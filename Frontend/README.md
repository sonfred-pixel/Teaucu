# TEAU CU Website

Official website for **TEAU CU Communications Department**, built with
plain HTML, CSS, and JavaScript. 

## Project Structure

```
.
├── index.html          # Main entry point
├── family.html
├── Giving.html
├── Ministries.html
├── Programmes.html
├── Css/
├── Css/                # Stylesheets
├── Javascript/                 # Scripts
├── Images/             # Images, Logos
└── LICENSE.txt          # License and ownership terms
```


## Getting Started

This is a static site — no build step, installation, or server-side dependencies are required to run it locally.

Clone or download the project files.
Open index.html directly in a browser (double-click the file, or right-click → Open With → your browser of choice).

## Deployment

Upload the contents of this folder to any standard static web host
(e.g. shared hosting, Netlify, Vercel, GitHub Pages, or a
department-managed server). No environment variables or backend
services are required unless added separately.

## Editing the Site

- **HTML** — page structure and content lives in `.html` files.
- **CSS** — styling lives in the `css/` folder.
- **JS** — interactive behavior lives in the `js/` folder.
